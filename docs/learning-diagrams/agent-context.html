Окремі вікна + handoff

Кожна роль отримує потрібне для свого рішення. Reviewer може перевіряти результат окремо від процесу написання коду. Це вимагає якісного handoff і може збільшити загальну витрату токенів.

Це модель QAuto-процесу, а не вимір фактичних токенів. Обсяг успадкованої розмови залежить від параметра запуску агента. Секрети з локального config не показують у handoff або evidence. Джерела: шаблон handoff, правила QAuto, офіційна документація OpenAI про multi-agent.
