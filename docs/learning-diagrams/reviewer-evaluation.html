Крок 1 · Матеріали

З чого починається перевірка

Папка сценарію містить вимогу, докази та два файли коду. Поле fixture в еталоні вказує саме на цю папку.

evaluation/cases/REV-04/
examples/ — зразки відповідей для демонстрації score.test.mjs — тести самого оцінювача (npm run eval:check)

Це синтетична вправа: оцінювач не запускає Playwright і не перевіряє зміст пояснень замість людини.
