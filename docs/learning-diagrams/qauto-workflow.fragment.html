Кейс у Notion

Користувач називає сторінку й номер кейса. Analyzer шукає рівно один рядок у таблиці цієї сторінки.

Запуски Playwright Test0 / 2
АртефактПовний case ID з Notion
«Автоматизовано» в NotionБез змін

Кожен запуск тесту має --retries=0. Невдалий запуск теж входить у ліміт 2/2. Статуси й результати вище умовні.

Папки проєкту — відкрийте для пояснення

pages/Page Object: локатори та дії

Кореневі *.page.ts зберігають перевірені локатори й дії користувача. Ключові очікування залишаються в тесті.

tests/Сценарії та assertions

Кореневі *.spec.ts містять дані, кроки, expect(...) та повний case ID у назві тесту.

generated/diffs/Версії patch і статусні зміни

Тут зберігаються початковий diff, окремі виправні diff і diff для оновлення Notion. Попередні версії не перезаписують.
