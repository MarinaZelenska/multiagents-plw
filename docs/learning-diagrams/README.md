# Навчальні схеми QAuto

- [Інтерактивний симулятор процесу](qauto-workflow.html) — відкрийте цей файл у браузері для заняття.
- [Сценарій 60-хвилинної лекції](qauto-workflow-lecture-60min.md) — таймінг, текст викладача, демонстрації, питання та підсумкова перевірка знань.
- `qauto-workflow.fragment.html` — вихідний фрагмент для редагування схеми.
- [Контекстні вікна агентів](agent-context.html) — обирайте роль, момент роботи й спосіб передавання історії, щоб побачити, які дані вже у вікні, які потрібно прочитати та які залишаються поза ним.
- [Оцінювання Reviewer](reviewer-evaluation.html) — інтерактивна схема практикуму з кейсами в [`evaluation/`](../../evaluation/README.md).

Студенти обирають результати на кожному етапі й бачать відповідну гілку, лічильник запусків, артефакти та умовний статус колонки `Автоматизовано`. Можна повернутися на крок і пройти інший маршрут. Папки розкриваються для пояснення їхньої ролі. Симулятор не запускає тести й не змінює Notion.
