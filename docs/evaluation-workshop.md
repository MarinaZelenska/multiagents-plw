# Заняття: оцінювання Reviewer (35 хв)

Мета: студенти проводять незалежне рев’ю Playwright-коду за вимогою, locator evidence і результатом запуску; потім зіставляють свої findings із golden set у [`evaluation/`](../evaluation/README.md). [Інтерактивна схема](learning-diagrams/reviewer-evaluation.html) показує етапи вправи. Перед заняттям достатньо `npm ci`. Браузер і Notion не потрібні.

| Час | Дія |
|---:|---|
| 0–5 хв | Відкрийте `evaluation/cases/REV-01/`: `context.json`, Page Object і spec. Попросіть назвати вердикт без вигаданих зауважень. |
| 5–12 хв | Розберіть `REV-02` і `REV-04`: зіставте locator в коді з CLI evidence. Запустіть `evaluation/examples/locator.json` і обговоріть, чому XPath та `.first()` потребують конкретних зауважень. |
| 12–20 хв | Студенти переглядають `REV-03` і записують два findings у JSON. Запустіть `npm run eval -- --submission evaluation/examples/correct.json` та порівняйте з `broken.json`. |
| 20–28 хв | Дайте `REV-05` для самостійного рев’ю: перевірте повноту assertions і fixed wait. Студенти створюють власний submission і запускають CLI. |
| 28–35 хв | Покажіть `REV-06`: успішний код не виправдовує `VALID`, коли фактичний запуск невдалий. Обговоріть, що автоматичний бал бачить ID і місце findings, а зміст виправлення перевіряє людина. |

Питання для підсумку: які проблеми пропустив Reviewer; чи є хибні зауваження; чи вказано правильний рядок; чи пояснено наслідок і конкретне виправлення; чи відповідає вердикт evidence. Правила формату та команди — в `evaluation/README.md`.
