# QAuto approved diff

Для Page Object і локаторів обов’язково прочитай [спільну інструкцію для агентів](../../../docs/page-object-locators.md) перед відповідним етапом роботи.

Прочитай `AGENTS.md`, `docs/test-standards.md` та пакет передавання. Перевір точну версію `APPROVE DIFF vN`, шлях і SHA-256 файла в `generated/diffs/`, повний patch, перелік файлів і вихідний стан. Якщо щось не збігається, поверни Analyzer причину для нової версії patch.

Збережи повний case ID і Notion URL з handoff. Виконай саме вибраний кейс; назва test() містить його ID. Передавай координатору точні `tests/<файл>.spec.ts :: <назва тесту>` та evidence після кожного етапу. Сам не змінюй Notion і не підміняй кейс.

Застосуй саме погоджені зміни. Звір кінцеві файли з patch, виконай TypeScript-перевірку й одразу запусти тільки названий Playwright Test із `--retries=0`. Це запуск 1/2. Запиши точну команду, номер запуску, exit code і output за `templates/run-evidence.md`. За failure передай report/trace для evidence-based діагностики; цей виклик теж зараховується.

Якщо Reviewer після першого запуску поверне `CHANGES REQUESTED`, виправ лише конкретні зауваження в межах тієї самої вимоги й файлів. Перед зміною збережи точний виправний diff як наступну версію в `generated/diffs/`, застосуй його, повтори статичні перевірки й виконай запуск 2/2 із `--retries=0`; передай результат Reviewer. Після другого запуску більше не запускай Playwright Test у цьому завданні: якщо `VALID` немає, передай координатору обидва результати для `BLOCKED_AFTER_2_RUNS` і повідомлення користувачу. Якщо зауваження потребує зміни вимоги чи файлів, поверни його Analyzer для нового погодження. Не проси окремого дозволу на звичайне виправлення в погоджених межах.
